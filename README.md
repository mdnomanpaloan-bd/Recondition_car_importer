# Reconditioned Car Importer & Management System

A production-ready **JavaFX 17 + FXML** Object-Oriented application designed for a Reconditioned Car Importer & Showroom business.

## 🚀 Features & Architecture

Built with **MVC (Model-View-Controller)** pattern, **Binary File Persistence (`.bin`)**, and standard JavaFX controls.

### 👤 USER 5: Showroom Manager (Goals 1–8)
1. **Manage Inventory & Showroom Cars** (`manage_inventory.fxml`)
2. **Assign Cars to Sales Representatives** (`assign_sales.fxml`)
3. **Set Vehicle Pricing & Discounts** (`vehicle_pricing.fxml`)
4. **Approve Customer Test Drive Requests** (`test_drive_requests.fxml`)
5. **Monitor Sales Rep Performance** (`sales_performance.fxml`)
6. **Track Vehicle Sales & Booking Status** (`track_sales_booking.fxml`)
7. **Handle Customer Complaints & Escalations** (`customer_complaints.fxml`)
8. **Generate Monthly Showroom Sales Reports** (`sales_reports.fxml`)

### 💼 USER 6: Finance Officer (Goals 9–16)
9. **Generate & Issue Invoices** (`generate_invoice.fxml`)
10. **Process Customer Payments & Installments** (`process_payments.fxml`)
11. **Approve Car Financing & Loans** (`car_financing.fxml`)
12. **Calculate Taxes, Import Duty & Customs** (`calculate_taxes.fxml`)
13. **Manage Showroom Expense Records** (`showroom_expenses.fxml`)
14. **Process Employee Salary & Commissions** (`employee_salary.fxml`)
15. **Track Profit, Revenue & Profit Margin** (`track_profit.fxml`)
16. **Generate Financial Audit & Tax Reports** (`financial_audit.fxml`)

## 🛠️ Project Setup & How to Run

### Prerequisites
- **JDK 17** or higher
- **Apache Maven** (optional, recommended for CLI)

### Running via Maven CLI
```bash
mvn clean javafx:run
```

### Running via IDE (IntelliJ IDEA / NetBeans / Eclipse)
1. Open project root (`pom.xml`).
2. Reload Maven project dependencies.
3. Run `MainApp.java` located at `src/main/java/com/example/recondition_car_importer/Sifat/MainApp.java`.
